# ARES integration: a contract-first recommendation

Candidate case study for the Energy Systems and AI Research Lead role, NEST
programme, Open Earth Foundation.

Prepared 29 August 2026. The commit history of this repository spans the work.

## What is here

| Path | What it is |
|---|---|
| `deck/` | The board deck, eight slides, pptx and PDF |
| `src/` | The artifact: the contract model, the checker, the page generator |
| `data/` | Partner interface declarations, synthetic, derived from the brief |
| `docs/` | Decisions taken, what was deliberately not built, and the AI-use disclosure |

## The argument in one line

The interface is the boundary, and tight coupling is necessary exactly to the
extent that the boundary is underspecified.
